게임 설명서

기본적으로 클릭만을 이용한 게임입니다.

시작씬
게임 시작 -> 난이도 선택
게임 종료 -> 게임 종료됨

로비씬
종족,배틀 -> 이름부분을 선택해서 사용및 배틀 가능
훈련 - > 돈은 공유하나 강화능력치는 각 종족마다 별개로 저장 되니 주의
스탯 -> 능력치 확인
앨범 -> 다른종족과 싸워서 이기면 획득 이미지
설정 ->  사운드 조절 및 시작씬으로 이동
튜토리얼 ->  간단한 설명과 스토리 내용
놀러가기 -> 배틀에 해당하며 이름부분을 눌러서 찾아감
일기 적기 -> 저장하기
일기 보기 -> 불러오기

배틀씬
윷 던지기 -> 윷이 자동으로 정해짐
윷 사용하기 -> 왼쪽 상단에 버튼을 윷 이름이 적힌부분을 클릭하기
말 이동 -> 새로 출발할 때는 왼쪽 하단에 작은 자기 이미지 클릭시 출발함
이미 나와있는 말이라면 나와있는 말을 클릭시 움직임
<윷 던지기가 나와있으면 윷을 사용해서 말을 움직일 수 없고 윷을 다 던지고 이용가능하며 도,개,걸,뒷도등은 하나만 저장 되기에 모나 윷을 이용해서 잡고 한번 더 던질때 도개걸뒷도가 있으면 지워지니 주의>
말까지 다 움직였으면 턴 넘기기를 눌러서 턴을 넘길 수 있고, 움직이는게 맘에 안들거나 윷을 던지기 싫을 때는 그냥 턴을 넘겨도 상관없다.
낙이 나오면 모든 윷을 잃어버리고 턴 넘기기 및 스킬 발동 말고는 할 수가 없다.

스킬 사용 -> 최대 3번 가능하며 자기 차례일 때만 사용가능하고
휴먼 => 한턴 동안 잃은 체력 비례해서 방어력이 상승
고블린 => 사용한 후 다음 적을 잡을 때 납치 확률에 따라 적의 최대 말 갯수를 하나 줄이고 자신의 최대 말 갯수를 하나 늘린다.
엘프 => 스킬 버튼 누르고 밖에 나와있는 엘프를 클릭하면 클릭한 엘프를 기준으로 자신의 사거리만큼 안에 존재하는 적 한칸을 잡을 수 있는데 기준은 업은 말이 많은 쪽을 기준으로 잡습니다.
<단 자신의 자신의 길 상태가 다른 적은 가까워도 스킬로 잡을 수 없음>
(길상태)
가장 바깥 테두리 ( 길상태 겨울)
우측상단에서 가온데를 통해서 골인 하는 루트 ( 길상태 가을)
우측 상단에서 좌측 하단까지 내려가고 골인 하는 루트 (길 상태 여름)
좌측 상단에서 골인 하는 루트 (길상태 봄)
간결하게 말하면 대각선과 바깥테두리는 길 상태가 다르기 때문에 엘프 스킬로 잡을 수 없다.
언데드 => 스킬 사용한 후 다음에 적을 잡을 때 적을 잡으면서 자신의 업은 말 갯수를 하나 늘린다.
엔젤 -> 스킬을 사용하고 밖에 나와있는 말을 선택하면 그 말이 카운터 상태로 바뀌며 3턴동안 카운터를 하는데 잡히면 일정 확률로 부활하여 잡으러 온 상대방을 잡고 살아 남는다.

스킬을 발동하기 위해서는 행운이 높아야하고 적 또한 방해율을 들고 있어서
행운이 방해율보다 높으면 스킬이 발동 됨
그 다음에 사거리 및 감염 확률 부활 확률등 확률에 따라 발동
휴먼,엘프는 확률 상관없이 성공하면 사용됩니다.

말이 업을 수록 데미지가 점점 강해진다.
말을 업으면 빨주노초파남보로 바뀌며 보라색(7마리를 업으면 보라색이 됨)  보라색이 되면 상대 적에게 처형급에 데미지를 줄 수 있다.

골인을 해서 데미지를 줄 수 있고 상대방 체력을 0으로 만들면 승리하고 로비로 돌아갈 수 있으며  다음 상대에게 도전 가능하다.
패배시 돈을 얻고 로비로 돌아갈 수 있다.

일기 적기를 통해 저장 된 내용은 나갔다가 돌아와도 일기 보기로 되돌릴 수 있다.
